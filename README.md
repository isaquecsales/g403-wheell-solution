solution for central wheell that doesnt work
**How to Use Logitech G403 Side Buttons for Scrolling on Bazzite Linux (KDE Wayland)**

My Logitech G403 Prodigy mouse had a broken scroll wheel, so I configured its side buttons to scroll up and down on Bazzite Linux with KDE Plasma on Wayland.

The solution uses **xremap + ydotool**, with systemd user-service autostart. I tested it successfully, including after reboot.

The guide includes the configuration, service setup, and troubleshooting steps.

I hope this helps someone else keep using their mouse instead of replacing it!
